5. Protocol and outputs
The frozen selection uses one complete selected public pair in each of 74 domains.
Seeds: 20261014, 20261015, 20261016; nested budgets: 0,1,3,7,15,31.
ALC weights: 0.1,0.2,0.2,0.2,0.2,0.1.
The local item split assigns ceil-half to acquisition and the remaining items to
evaluation. Candidate order and selected acquired response are SHA-256 ranked.
The default query is replayed with its remaining-budget context. Each acquired
item supplies one recorded label. At each budget the actual frozen predict()
functions are freshly loaded, predictions are cached only within that checkpoint
by complete visible input, and all graded evaluation responses have equal weight.
Only allowed visible attributes and purchased labels enter the model.

The new output contains public_summary.json: domain/seed budget scores, aggregate
ALC, descriptive bootstrap interval, environment, and integrity hashes. It does
not output original questions, per-item labels, raw responses, or acquisition
trajectories. The included reproduction/public_summary.json records the completed
release-validation run, not a fresh independent statistical test.
The public-reference comparison checked 4,017 numeric values, maximum absolute
difference 1.6653345369377348e-16 (required tolerance 1e-12).
Laplace ALC: 0.22503754069056203; Jeffreys ALC: 0.23094111247206206.
74 domains / 222 domain-seed results / 296 source tables verified.

prepare_metadata.py is a provenance utility that extracts only whitelisted public
selection metadata and public J/A summary values from earlier local public files.
Normal reproduction uses the committed frozen manifests and does NOT need to run
this utility or possess those earlier files. core/ modules retain source provenance
and are exact copies of the project's public protocol/data-schema code.

6. Interpretation and disclosure
These 74 domains were previously inspected during development; this is not a blind
holdout or 222 independent domains. Domain-cluster bootstrap describes this panel.
Item split, NULL filtering, recorded-response selection, and acquisition ordering
are explicit local assumptions, not a byte-for-byte hidden coordinator replica.
The analysis does not reproduce official private ALC or perform private-score
counterfactuals. Different formative submissions are unpaired and may overlap.
The final runtime model uses no fitted public prior or LLM inference.
LLM-based assistants through WorkBuddy helped coding, debugging, analysis, and
report drafting. The project has historical private-feedback-derived exploratory
analyses; those are discontinued, are not in this release, and the whole project
is not characterized as clean-room. Organizer interpretation of historical scope
remains distinct from this public reproduction.
